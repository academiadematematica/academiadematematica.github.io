Exercício 10

O programa seguinte, escrito em Python, simula 100 amostras de dimensão 40 de uma população Normal com μ=50\mu = 50μ=50 e σ=10\sigma = 10σ=10 e, para cada uma, constrói um intervalo de 95 % de confiança para μ\muμ.

import random
import statistics

mu = 50
sigma = 10
n = 40
amostras = 100
contem = 0
for i in range(amostras):
    amostra = [random.normalvariate(mu, sigma)
               for j in range(n)]
    media = statistics.mean(amostra)
    s = statistics.stdev(amostra)
    margem = 1.96 * s / n**0.5
    if media - margem <= mu <= media + margem:
        contem = contem + 1
print(contem)

  1. 10.1. O que representa o valor apresentado pelo programa?

  2. 10.2. Numa execução, o programa apresentou 93 e, noutra, 94. Que valor esperava obter? Estes resultados contradizem o nível de confiança de 95 %? Justifique.

  3. 10.3. Que alteração faria para simular intervalos de 99 % de confiança?

Ver resolução

Simulação de intervalos de confiança em Python.

  1. 10.1. O número de intervalos, entre os 100 construídos, que contêm o verdadeiro valor de μ\muμ (=50= 50=50).

  2. 10.2. Esperava cerca de 95. Não há contradição: o nível de confiança é a proporção de intervalos que contêm μ\muμ a longo prazo; em 100 intervalos, o número observado varia de execução para execução (93, 94, 96, …). Aumentando o número de amostras, a proporção aproxima-se de 95 %.

  3. 10.3. Substituir 1.96 por 2.576.

Exercício 14
