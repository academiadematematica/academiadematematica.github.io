Preparação para a Prova de Maiores de 23

Curso online de preparação para o acesso ao ensino superior. Formação estruturada em horário pós-laboral.

Um percurso estruturado para o ensino superior

Este curso foi concebido para candidatos que pretendem ingressar no ensino superior através do regime Maiores de 23, com acompanhamento académico orientado e preparação focada na prova de acesso.

💻Modalidade

Curso 100% online, com aulas em direto.

📅Início do curso

Primeira semana de fevereiro de 2027.

⏱Horário

Pós-laboral, compatível com atividade profissional.

🎯Objetivo

Preparação completa para a prova de acesso ao ensino superior.

👥Vagas

Número de alunos limitado, para garantir acompanhamento individualizado.

📚Estrutura pedagógica

48 horas de conteúdos organizados de forma progressiva e orientada para a prova. Ver programa.

Porquê este curso?

O regime Maiores de 23 exige não apenas conhecimento, mas preparação estratégica para a avaliação. Este programa foi estruturado para colmatar lacunas de formação e desenvolver as competências essenciais para o sucesso na prova.

  • Metodologia orientada para exame
  • Apoio na organização do estudo
  • Simulações de avaliação
  • Preparação progressiva e estruturada

Pré-inscrições abertas

As vagas são limitadas e preenchidas por ordem de candidatura.
